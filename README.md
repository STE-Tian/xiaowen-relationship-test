# 小文的异性边界测试

一个为朋友聚会设计的轻量级网页小游戏：通过 40 个日常情境，看看你能接受小文和异性相处到什么程度。

## 在线体验

GitHub Pages 部署完成后访问：<https://jizetian.github.io/xiaowen-relationship-test/>

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装依赖、无需后端服务。

## 功能

- 40 道原创情境题，覆盖日常社交、亲密互动、深夜相处、暧昧边界和高争议行为
- 三种选择：能接受、看情况、不能接受
- 自动保存答题进度到当前浏览器的 localStorage
- 结果统计、逐题回顾、复制结果、重新测试
- 适配手机和桌面浏览器

## 隐私说明

本项目没有账号系统、后端或数据收集。答题记录只保存在当前浏览器本地存储中。清除浏览器站点数据会删除本地进度。

## 免责声明

本测试仅供朋友间娱乐和交流，不代表对任何人的评价，也不构成感情关系的判断标准。

## 部署

仓库通过 GitHub Actions 将根目录静态页面发布到 GitHub Pages。首次部署后，可在仓库 Settings → Pages 中确认 Source 为 GitHub Actions。
